# journal 6
I've been taking this time to reflect on how my first mini project aligns with the readings. I think what I retained was how data becomes subjected to changes, especially online. It can be easily recognizable to thoroughly changed that the source gets lost. How do I want to change the data the user gives me? While I think the righteous thing would be to leave it as is and just mirror back the raw data, deep down I think cutifying it would be a fun answer. I was thinking aesthetically such as colour changes, but also with the content itself. The ASCII modification is my desired one, but I think using input text and changing the output to something ridiculous has potential as well. There are also references to how it is collected. For this project, I will focus on it being collected by the user itself, rather than from an external source. I think it will be easier for me to focus solely on one data collection method, rather than many, however that can be something to think about.
